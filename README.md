# KitchenWatch

> Inventory control and QR ordering for modern restaurant groups.

KitchenWatch gives restaurant owners one simple dashboard to control inventory, wastage, and transfers across every outlet, and lets customers order by scanning a QR code.

## Tech Stack
- **Framework:** React + Vite + TypeScript
- **Styling:** Tailwind CSS
- **Motion:** Framer Motion + Lenis Smooth Scroll
- **3D Graphics:** Three.js / @react-three/fiber / @react-three/drei
- **Icons:** Lucide React

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
